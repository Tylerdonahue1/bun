# Journal

One file per person per day: `YYYY-MM-DD-tyler.md` or `YYYY-MM-DD-iryna.md`.

Append to your own file. Never edit someone else's. If you work more than once in a day, add another short section to the same file.

Keep each entry short:

- What you did
- Decisions (and whether you also logged them in `DECISIONS.md`)
- Leftover questions
- Links to PRs or commits

Sign with your name and a timestamp that includes a zone label.
